# 开发工作流

1. 从 AGENTS.md 路由到当前任务相关资源。
2. 阅读涉及的代码和实际来源样本，明确本次交付结果。
3. 按 ponytail 实现当前目标所需改动。
4. 运行相关已有检查，使用实际材料确认输出。
5. 更新对应的小文档并提交 Git。
6. 需要线上使用时，从本地 Git 工作区同步已跟踪文件到服务器，按部署文档重启受影响的服务。

模块职责保持清晰：日历边界、来源计算、数据库操作和运行调度分别组织。

当前接口固定版本为 operators-v0.1.0。历史准备资料在[历史索引](../history/index.md)中，正式实现以代码和当前资源文档为准。

相关资源：[文件地图](../project/files.md)、[验证](../operations/verification.md)。
